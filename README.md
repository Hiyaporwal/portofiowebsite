# Hiya Porwal — Personal Portfolio Website

> **Computational Data Science | Data • AI/ML • Software**  
> Integrated M.Tech Computational Data Science Student at VIT Bhopal University (2023–2028).

An original, storytelling-driven portfolio website engineered to showcase technical depth across Data Analytics, Business Intelligence, Machine Learning, Generative AI, and Software Engineering.

---

## 🌟 Key Features

- **Abstract Computational Architecture Visual**: Interactive graph node ecosystem linking the central Core to Data, AI/ML, Software, and Analytics.
- **Editorial Personal Statement & Approach**: Highlights end-to-end capabilities from raw data manipulation to dashboards, predictive models, and full-stack systems.
- **Interactive Toolkit**: Organized by category (Data & Analytics, AI/ML, Software, Databases, Tools, Languages) with real project tags and zero fabricated percentages.
- **Industry Timeline**: Verifiable metrics across 3 technical internships (SVS Datalytics, Hindustan Copper Limited, ParshWebCraft).
- **Featured Projects**:
  - **RecovAI**: AI decision support for Hindustan Copper's Malanjkhand concentrator plant (1,640 shift records, XGBoost, SHAP).
  - **ParshvTrack**: Field workforce management ERP with live GPS tracking, geo-tagged attendance, and PostgreSQL backend (50+ active users).
  - **RAG PDF Chat**: Retrieval-Augmented Generation using LangChain, ChromaDB vector store, HuggingFace embeddings, and Groq Llama 3.3 70B.
- **Data in Action Showcase**: Interactive category filters (`ALL`, `DATA & BI`, `AI / ML`, `SOFTWARE`, `GENAI`) featuring the Uber Power BI dashboard, Blinkit EDA, Netflix EDA, and more.
- **Deep Case Study Modals**: Structured views detailing the Problem, Approach, Hiya's specific individual contribution, Tech Stack, and Documented Results.
- **Printable Resume Viewer**: Built-in resume viewer modal with one-click print-to-PDF functionality.
- **Beyond the Code**: Genuine personal dimensions (Dance, Public Speaking, Collaborative Learning, Fitness & Yoga).
- **Quick Recruiter Composer**: Pre-populates contextual email drafts based on selected role specialties.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React + Custom SVG Icons
- **Deployment**: Vercel ready (`vercel.json`)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

---

## 🌐 Deploy to Vercel

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Hiya Porwal Portfolio"
   git branch -M main
   git remote add origin https://github.com/Hiyaporwal/portfolio.git
   git push -u origin main
   ```
2. Import the repository into [Vercel](https://vercel.com).
3. The framework preset will automatically detect Vite. Click **Deploy**.
